# Buildspawn

Buildspawn is a self-hosted build server for game studios. It works with Perforce and Git, Unity and Unreal Engine, agent pools for every platform, and Steam and Epic Games Store publishing.

- **Website and user guide:** https://creativewild.github.io/buildspawn/
- **Downloads:** [Releases](https://github.com/creativewild/buildspawn/releases). Every download includes Java 21.
- **Release notes:** [release-notes/](release-notes/)

## What is in this repository

| Path | What it is |
|---|---|
| `index.html`, `assets/` | The website |
| `docs/` | The user guide: 309 pages and 58 how-to guides |
| `release-notes/` | The notes of every release |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are |

The site is plain HTML, CSS and JavaScript, with no build step. Search uses `assets/search-index.js`, which is made from the guide pages.
