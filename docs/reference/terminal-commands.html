Terminal program commands

Every command, option and key of the buildspawn terminal program, in one place.

The terminal program comes with every server download. On Windows it is bin\buildspawn.exe; on Linux and macOS it is bin/buildspawn. The Linux packages and Windows setup put it on the PATH, so there you just type buildspawn. For a walk-through of the screens, see The terminal program, and for how it behaves, The server terminal program.

How to call it

buildspawn [command] [options]

With no command it opens the terminal interface: the launch flow on a first run, otherwise the live monitor. Without a terminal, for example in a scheduled task, it prints the status instead.

Commands

Set up

CommandWhat it does
buildspawnOpens the launch flow on a first run, otherwise the live monitor.
launch [--preset NAME] [--yes]Opens only the launch flow. --preset fills it from a saved preset and skips the start screen. --yes accepts every default.
preset listLists the saved launch presets.
preset save NAMESaves the current settings as a preset.
preset delete NAMEDeletes a preset.
admin-password [--copy]Prints the initial admin password while it exists. --copy puts it on the clipboard instead.
checkChecks the settings file and Java, and prints the full Java command.
versionPrints the version and build (also --version and -v).
helpLists every command and option, and ends with the settings file this copy uses (also --help and -h).

Run, start and stop

CommandWhat it does
runRuns the server in this terminal until you press Ctrl + C. The services use this too.
startStarts the service when one is installed for this copy. Otherwise starts the server in the background.
stopStops the service, or the background server.
restartStops it and starts it again.

The service

The service is a Windows service, a systemd service on Linux, or a LaunchAgent on macOS.

CommandWhat it does
service statusShows whether a service is installed, whether it runs and whether it starts at boot.
service installInstalls the service and starts it.
service removeRemoves the service. The home, the logs and the settings stay.
service enable / disableTurns start at boot on or off.
install-serviceThe same as service install. Options: --user NAME (Linux: the system user to run as, buildspawn by default), --no-start (install but don't start), --dry-run (only say what would be done).
uninstall-serviceThe same as service remove. --remove-user (Linux) also deletes the system user, but not its files.

Every service command takes --dry-run. Actions that need administrator or root rights ask first: Windows shows its permission prompt, and on Linux the program runs sudo only after you answer y.

Watch the server

These are the text twins of the monitor's views, for use in scripts. The table commands print plain text, or JSON with --json.

CommandWhat it prints
status [--json]Where this copy is, whether it runs, the URL, the home folder, and counts of builds, queue and agents.
builds [--running | --failed] [--limit N] [--json]The Builds table: only running builds, only failed builds, or the last N builds.
queue [--json]The Queue table, with the reason each item waits.
agents [--json]The Agents table.
logs [-f] [--level warn] [--filter TEXT] [--source gc]The server log. With no option it follows the log. --level hides lines below that level, --filter keeps only lines with the text, and --source gc shows the Java memory (GC) log.

Trusted certificates

Manages the trust folder in the home: company root certificates that Java must trust. It works on this computer's home and does not need the server to run. Changes take effect when the server starts again. See Trusted certificates.

CommandWhat it does
certs listShows the trust folder, the Windows store setting, the added certificates and whether a restart is needed.
certs add FILEAdds the certificates in a .pem, .crt, .cer, .der, .p7b or .p7c file. Shows each one and asks before adding. Use - as the file to read text from standard input (this needs --yes).
certs remove FINGERPRINT-OR-NAMERemoves one added certificate. The fingerprint can be its first characters, with or without colons.
certs windows-store on|offAlso trust the certificates the Windows certificate store trusts. Windows only.

Options for certs: --yes (do not ask), --include-expired (with add: also add expired certificates) and --home DIR (name the home folder when the settings file does not show it).

buildspawn certs add company-root.crt --yes
buildspawn certs windows-store on

Change settings

CommandWhat it does
set key=value ...Changes the settings file. Keys: port, listen, memory, home, logs, java-options, arguments.
set ... --applyAlso restarts the server, after asking.
set ... --apply --yesRestarts without asking.
 
buildspawn set port=8090 memory=8g --apply

See Settings files for what each key means.

Exit codes

CodeMeaning
0Success. For status: the server runs.
1The command failed.
2The command or its options were wrong.
3For status: the server is stopped.
 
buildspawn status --no-tui > /dev/null || echo "Buildspawn is not running"

Options

These work with every command and with the terminal interface.

OptionWhat it does
--no-tuiNever opens the terminal interface. With no command it prints the status.
--view NAMEOpens the monitor on a view: overview, builds, queue, agents, logs, service or settings. Names that start with launch open a step of the launch flow.
--onceDraws one frame as plain text and exits. Good for a quick look or a log file.
--cols NForces the layout width. 80 to 109 gives the narrow layout, 110 and up the wide one.
--theme NAMEColours: color, light or mono.
--no-colorNo colours. The same as setting NO_COLOR=1.
--glyphs NAMESymbols: unicode, ascii or solid.
--interval 2sHow often the monitor refreshes.
--url URLWatches another server instead of this copy.
--token-file PATHA file whose first non-empty line is user:token (or just the token). It allows actions such as stopping a build. The program never prints it. See API tokens.
--api-user NAMEThe user name to send with a token that has no user: in front.
--rows NForces the screen height in rows (8 or more). Used with --once.
 
buildspawn --url http://buildserver:8080/ --view queue
buildspawn --once --view agents --no-color

Environment variables

VariableWhat it does
BUILDSPAWN_URLThe server to watch, like --url.
BUILDSPAWN_TOKEN_FILEThe token file, like --token-file.
BUILDSPAWN_TOKENThe token itself, when you cannot keep a file. Prefer the file.
BUILDSPAWN_USERThe user name, like --api-user.
BUILDSPAWN_INTERVALThe refresh time, like --interval.
BUILDSPAWN_PRESETSUse another presets file.
BUILDSPAWN_THEMEThe colours, like --theme.
BUILDSPAWN_GLYPHSThe symbols, like --glyphs. The old Windows console gets ascii unless you set this.
BUILDSPAWN_CONFIGUse another settings file.
NO_COLORAny value turns colours off.
COLUMNSThe terminal width, when the program can't detect it.

Keys in the live monitor

Press ? in the monitor to see these at any time.

Anywhere

KeyWhat it does
1 to 7Overview, Builds, Queue, Agents, Logs, Service, Settings
TabNext view, or next tile on the Overview
/Filter the list. Esc clears it.
SpaceFreeze or resume the screen
rRefresh now
tNext colour theme
GNext glyph set
bOpen the web interface in your browser
?Help
qQuit. It asks whether to keep the server running or stop it.
Ctrl + CQuit and keep the server running

In each view

ViewKeys
Overview↑ ↓ select a build, Enter open its log
BuildsEnter log, o open in the browser, x stop the build, f result filter, g group by job
Queuec cancel the item, p move it to the front, Enter open the job page
AgentsEnter executors, o open the agent page, d take offline, n new agent
LogsTab source, l level, / filter, f follow, PgUp / PgDn scroll, c clear, s save
Services start, t stop, r restart, i install or update, u remove, a start at boot on or off
Settings↑ ↓ field, Enter edit, Esc cancel the edit, a apply and restart, w save and apply later, u undo changes

Stopping a build (x), cancelling or moving a queue item (c, p) and taking an agent offline (d) need an API token. Without one the monitor is read only. The Service and Settings views work without a token.

In the launch flow

KeyWhat it does
EnterNext step
EscPrevious step
e / d / nOn the start screen: edit, delete or rename the selected preset
v / cOn the password step: show or copy the password
Tab, ↑ ↓, ← →, SpaceMove between fields, choose, change a value and tick a box
b / sOn the home step: browse folders, and use the folder you are in
eOn the password step: set your own password. On the last step: edit a step
t / G / ? / qTheme, symbols, help and quit. Nothing is changed before Start.
