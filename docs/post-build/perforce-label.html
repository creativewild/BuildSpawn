Label in Perforce (VCS labeling)

Puts a label on the Perforce revision that the build used.

When to use it

It is the same setting as the build feature VCS labeling; all fields are described there. Use it to find the exact files of a build later.

How to set it up

  1. Open the build configuration, click Settings, then Post-build Actions. Click Add post-build action and choose Label in Perforce (VCS labeling).
  2. Set the Label pattern and Label builds.
  3. Click Save.

A worked example

Each good Windows Build gets the label skyforge-142. The artists sync that label to see the build's files.

What you see when it runs

The label shows on the Perforce Labels tab.
