Perforce: ApproveImpl review

Changes the state of a Helix Swarm review when the build ends, for example to approve it.

When to use it

Use it in a build that checks a review. A good build approves it. You can also use a vote or a change of state.

How to set it up

  1. Open the build configuration, click Settings, then Post-build Actions. Click Add post-build action and choose Perforce: ApproveImpl review.
  2. Choose the P4 Credentials.
  3. Type the Swarm Review number, usually as a variable such as ${review}.
  4. Choose the Approve Status.
  5. Type a Description. Click Save.

Every field

FieldWhat it doesDefaultExample
P4 CredentialsThe Perforce credential to use. It must be allowed to change the review.Nonep4-swarm-bot
Swarm ReviewThe review ID.Empty${review}
Approve StatusWhat to set: Needs Review, Needs Revision, Approve, Approve and Commit, Reject, Archive, Vote Up or Vote Down.NoneApprove
DescriptionA comment saved with the change.EmptyBuild ${BUILD_NUMBER} passed

A worked example

The shelf check build runs on a Swarm review and, if it passes, uses Vote Up with the description Build ${BUILD_NUMBER} passed.

What you see when it runs

The review shows the new state and your description.

Problems and fixes

ProblemWhat to do
Review not foundCheck the review ID.
Approve and Commit is refusedThe user needs permission to commit from Swarm.
