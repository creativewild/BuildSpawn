Send build artifacts over FTP

Sends files from the build to a server over FTP, when the build ends.

When to use it

Use it to put build output where other people or machines can get it. Use it for servers that only offer FTP. An administrator sets up the servers once in the global settings. The same form is also offered as a build step of a promotion, for build configurations that use promotions.

How to set it up

  1. Open the build configuration, click Settings, then Post-build Actions. Click Add post-build action and choose Send build artifacts over FTP.
  2. Click Add under Publishers and choose the server in Name.
  3. Add a transfer set: Source files and the other fields.
  4. Open Advanced for retries, labels and what to do on an error.
  5. Click Save.

A worked example

The nightly Docs build sends site/** to the web host over FTP with Transfer mode set to Binary, into the remote directory wiki.

What you see when it runs

The log shows the FTP connection and each file sent. An error makes the build unstable, or failed if you chose that.

Problems and fixes

ProblemWhat to do
Login incorrectCheck the credentials of the server in the global settings.
Files are damagedUse Binary transfer mode, not ASCII.
The server drops the connectionTurn on a retry in Advanced.
