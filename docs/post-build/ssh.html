Send build artifacts over SSH

Sends files from the build to a server over SSH, when the build ends.

When to use it

Use it to put build output where other people or machines can get it. You can also run a command on the server after the files arrive. An administrator sets up the servers once in the global settings. The same form is also offered as a build step of a promotion, for build configurations that use promotions.

How to set it up

  1. Open the build configuration, click Settings, then Post-build Actions. Click Add post-build action and choose Send build artifacts over SSH.
  2. Click Add under Publishers and choose the server in Name.
  3. Add a transfer set: Source files and the other fields.
  4. Open Advanced for retries, labels and what to do on an error.
  5. Click Save.

A worked example

The Linux Server Build sends Builds/Linux/** to the studio server build-share-01, into skyforge/nightly/2026-11-27 (date format yyyy-MM-dd), then runs ./restart-test-server.sh.

What you see when it runs

The log shows the connection, each file sent and the command output. An error makes the build unstable, or failed if you chose that.

SSH: Connecting from host [WIN-BUILD-02]
SSH: Transferred 412 file(s)
SSH: Exec command exit status: 0

Problems and fixes

ProblemWhat to do
Failed to connectCheck the server in the global settings, the key or password, and the firewall.
Prefix must be present in all file pathsRemove prefix must match the start of every sent path. Fix the pattern or the prefix.
Duplicate filename in flatten modeTwo files have the same name. Turn off Flatten files.
