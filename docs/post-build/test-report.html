Publish JUnit test result report

Reads test report files in JUnit format and shows the results on the build.

When to use it

Use it when your tests write XML reports. It is the same setting as the build feature XML report processing. The fields are described there. This page shows the short way.

How to set it up

  1. Open the build configuration, click Settings, then Post-build Actions. Click Add post-build action and choose Publish JUnit test result report.
  2. In Test report XMLs type the files, for example Reports/*.xml. Use Validate Pattern to check.
  3. Click Save.

Every field

The most used fields. All of them are in XML report processing.

FieldWhat it doesDefaultExample

Allow empty resultsDo not fail the build when no results are found.OffOff

A worked example

The Unit Tests configuration of the Engine project writes Reports/tests.xml. The post-build action reads Reports/*.xml.

What you see when it runs

The build page gets a Tests tab. A build with a failed test is Unstable.

Problems and fixes

ProblemWhat to do
