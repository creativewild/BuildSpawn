Aggregate downstream test results

Collects the test results of the builds that follow this one and shows them together on this build.

When to use it

Use it when one build compiles and several others run tests, for example a PS5 test build and a Windows test build that start after Windows Build. People then see the whole test result on one page.

How to set it up

  1. Open the build configuration, click Settings, then Post-build Actions. Click Add post-build action and choose Aggregate downstream test results.
  2. Tick Automatically aggregate all downstream tests to take every build configuration that follows. Or type the names in Jobs to aggregate.
  3. Tick Include failed builds in results if failed downstream builds count too.
  4. Click Save.

Every field

FieldWhat it doesDefaultExample
Automatically aggregate all downstream testsTake the tests of every build configuration that follows this one, through the whole chain. You do not need to keep a list.OffOn
Jobs to aggregateA comma separated list of build configuration names, when you do not use automatic mode.EmptyGame/Unit Tests, Game/PS5 Tests
Include failed builds in resultsAlso count builds that failed.OffOff

A worked example

Windows Build starts Unit Tests and Smoke Tests when it passes. With automatic aggregation on, the Windows Build page shows the sum of all three.

What you see when it runs

The build page shows an Aggregated Test Result with the counts per downstream build configuration.

Problems and fixes

ProblemWhat to do
Nothing is aggregatedThe following builds must be started by this build (a trigger or a dependency) and must publish test results themselves.
The numbers change laterResults are added as the downstream builds finish.
