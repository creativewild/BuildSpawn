Perforce: Label build

Creates a Perforce label for the changelist that the build synced, with a name and description you choose.

When to use it

This is the label action of the Perforce root settings. Use it for a simple label. If you need a branch filter or a root choice, use Label in Perforce (VCS labeling).

How to set it up

  1. Open the build configuration, click Settings, then Post-build Actions. Click Add post-build action and choose Perforce: Label build.
  2. Set the Label Name and Label Description.
  3. Tick Only tag on build success if failed builds must not be labelled.
  4. Click Save.

A worked example

Release Build labels the synced changelist as skyforge-release-${BUILD_NUMBER} only on success.

What you see when it runs

The log says the label was created for the changelist.
