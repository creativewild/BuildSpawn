Archive the artifacts

Keeps files from the workspace with the build, so you can download them from the build page later.

When to use it

Use it for anything you want after the agent is cleaned: the game build, installers, crash symbols, logs. Archived files show on the Artifacts tab of the build. Later builds and other build configurations can use them as artifact dependencies.

How to set it up

  1. Open the build configuration, click Settings, then Post-build Actions. Click Add post-build action and choose Archive the artifacts.
  2. In Files to archive type the files, relative to the workspace, for example Builds/Win64/**.
  3. Open More options if you need to exclude files or change a switch.
  4. Click Save.

Every field

The General tab of the build configuration has the same idea under Artifact paths, with the form source => target folder. See General.

A worked example

The Windows Build of Skyforge writes its output to Output/. The studio sets Files to archive to Output/** and Excludes to **/*.pdb. The symbol files stay out; the 2 GB game package stays in.

What you see when it runs

The log says how many files were archived. The build page gets an Artifacts list with sizes.

Problems and fixes

ProblemWhat to do
No files found to archiveThe pattern did not match. Paths are relative to the workspace. Check that an earlier step made the files. Turn on Do not fail build if archiving returns nothing only if empty output is normal.
Disk is filling upArtifacts are kept as long as the build. Use retention to keep artifacts for fewer builds than the builds themselves.
Files outside the workspaceThey cannot be archived. Copy them into the workspace first.
