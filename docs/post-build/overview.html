After the build

Post-build actions run when the build steps have finished. They keep the files, report the tests, tell people and start other work.

How they work

  • They run in the order of the list, after the last build step.
  • A post-build action never changes how the steps ran. Some can change the result: a failed upload can make the build unstable or failed.
  • Open them in Settings › Post-build Actions of a build configuration. See the Post-build Actions tab.
  • A template or a project can pass post-build actions down to many build configurations.
