Perforce: Cleanup

Deletes the Perforce workspace (client) after the build.

When to use it

Use it with agents that are created and removed often, so the server does not collect old workspaces.

How to set it up

  1. Open the build configuration, click Settings, then Post-build Actions. Click Add post-build action and choose Perforce: Cleanup.
  2. Tick Delete Client. Tick Force Delete Client only if a normal delete fails.
  3. Click Save.

Every field

FieldWhat it doesDefaultExample
Delete ClientDelete the workspace spec after the build (p4 client -d).OffOn
Force Delete ClientForce the delete (p4 client -f -d).OffOff

A worked example

Cloud build agents that are thrown away each night use Delete Client, so the Perforce server does not keep a workspace per agent.

What you see when it runs

The log shows the workspace being deleted. Files on the agent are not touched.

Problems and fixes

ProblemWhat to do
Delete fails: the client has opened filesUse Force Delete Client, or revert the files first.
