UGS metadata server badge

Sets a badge for a changelist on an Unreal Game Sync metadata server, so developers see in UGS whether the changelist built.

When to use it

Use it with an Unreal Engine project in Perforce. The full page, with a worked example, is UGS metadata server badge in the Game builds section.

How to set it up

  1. Open the build configuration, click Settings, then Post-build Actions. Click Add post-build action and choose UGS metadata server badge.
  2. Type the Server URL and use Test connection.
  3. Type the Badge name and the Project depot path.
  4. Click Save.

Every field

FieldWhat it doesDefaultExample
Server URLThe metadata server, for example http://localhost:3000.Emptyhttp://ugs.studio.example:3000
BadgeThe badge name shown in UGS.EmptyEditor
ProjectThe depot path of the project folder, not the .uproject file.Empty//UE5/Main/Samples/Games/Lyra
CredentialsOptional. A Secret text credential sent as a bearer token. Metadata servers in a closed network usually need none.None-

A worked example

After the Windows Build, badge Editor for //UE5/Main/Skyforge turns green in UGS for the built changelist.

What you see when it runs

The log shows the update sent to the server. The badge changes in UGS.
