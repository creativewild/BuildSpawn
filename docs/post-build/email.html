E-mail Notification

Sends an email when a build fails, and when it is fixed.

When to use it

It is the same setting as the build feature Notifications. Use it when someone must hear about a broken build without opening Buildspawn.

How to set it up

  1. Open the build configuration, click Settings, then Post-build Actions. Click Add post-build action and choose E-mail Notification.
  2. Type the Recipients, separated by spaces.
  3. Choose the two options if you need them. Click Save.

Every field

FieldWhat it doesDefaultExample
RecipientsWhitespace-separated addresses. Build variables may be used.Emptybuild-team@studio.example
Send e-mail for every unstable buildOn: every unstable build sends mail.OnOn
Send separate e-mails to individuals who broke the buildAlso mail the people whose changes were in the broken build.OffOn

A worked example

Release Build mails release-team@studio.example. When the build breaks, the team gets one mail. When it is fixed, one more.

What you see when it runs

The mail comes from the server mail settings. Its subject says the build is failed, unstable or back to normal.

Problems and fixes

ProblemWhat to do
No mail arrivesAsk an administrator to check the mail server in the global settings.
Too many unstable mailsTurn off Send e-mail for every unstable build.
