Execute Windows batch command

Runs a Windows batch script with cmd. It is the classic step, kept as it was.

When to use it

Use it on Windows agents for plain .bat scripts. For new work, Command Line does the same and adds a code editor, stderr colours and container settings.

How to set it up

  1. Open the build configuration and click Settings › Build Steps.
  2. Click Add build step. Type Execute Windows batch command in Filter step types if you like, then click the Execute Windows batch command tile (group Other).
  3. Type a Step name, for example Run build script.
  4. Type the script into Command. Open More options for the unstable error level.
  5. Optional: set Execute step, Conditions and Retry on failure. See The steps list and the step editor.
  6. Click Save.

A worked example

A Windows agent runs the studio's build script and treats exit code 2 (warnings) as unstable. Step name Run build script, Command:

call Build\build.bat %CONFIG% || exit /b %errorlevel%

What you see when it runs

The console block is titled [Step 1/1] Run build script (Execute Windows batch command). The script is saved as a temporary buildspawn….bat file and run with cmd /c call. When the exit code equals the unstable value, the step is shown as unstable and the build continues.

Problems and fixes

ProblemWhat to do
The script ends with exit code 1 but you wanted successEnd the script with exit /b 0, or fix the failing command.
A variable shows as %NAME% textName it in the build configuration's parameters, or set it in an earlier step.
