SMB Upload

Copies files to a Windows or Samba share, with include patterns. It sends to a Windows file share.

In the step picker this is called Send files to a windows share.

When to use it

Use it to publish builds to the studio file server, so testers can fetch them from a share.

How to set it up

  1. Open the build configuration and click Settings › Build Steps.
  2. Click Add build step. Type SMB Upload in Filter step types if you like, then click the SMB Upload tile (group Upload and deploy).
  3. Type a Step name, for example Publish to share.
  4. Fill in the fields described below.
  5. Optional: set Execute step, Conditions and Retry on failure. See The steps list and the step editor.
  6. Click Save.

A worked example

Publish the Windows build to the share. Step name Publish to share, Name build-share, Source files Builds/Windows/**, Remove prefix Builds/Windows, Remote directory Skyforge/%build.number%.

What you see when it runs

The console says it is connecting, then Transferred N file(s), then disconnecting.

Problems and fixes

ProblemWhat to do
Access deniedThe account in the server settings needs write rights on the share.
The share list is emptyAn administrator must add the share under Settings › System.
