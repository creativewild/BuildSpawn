Steam upload: overview

Buildspawn can send your game build to Steam, check that Steam has it, and set it live on a beta branch, all from build steps.

When to use it

Use these steps when your studio ships on Steam and you want every good build to reach a Steam branch without anyone running tools by hand. Steam delivers games with SteamPipe. You upload files to Steam, and players download only the parts that changed.

Words you need

WordWhat it means
App IDThe number Steam gives your game, for example 1000480.
DepotA group of files in the app. Studios often use one depot per system or language. Each depot has its own number.
Build IDThe number Steam gives to one upload.
BranchA named channel players can opt into, such as nightly. Players do not see a build until you set it live on a branch.
SteamCMDValve's command-line tool that does the upload. The steps run it for you on the agent.
Build accountThe Steam account the upload signs in with. You store it as a Steam build account credential.

The steps

All Steam steps are in the Upload and deploy group of the step picker.

Install SteamCMD

Download SteamCMD on an agent that does not have it.

Steam upload

Upload depots to Steam, and optionally set the build live on a branch.

Steam: DRM wrap

Wrap a program with the Steam DRM wrapper on its own.

Steam: check build

Wait for the build to show on Steam and check that a branch exists.

Steam: set branch live

Set a build live on a branch after your tests pass.

Steam: workshop item

Create or update a Steam Workshop item.

The account used by the steps that run SteamCMD is described on Steam build account.

How the pieces fit

  1. Add a Steam build account credential and sign in once.
  2. Add Install SteamCMD as the first step, unless your agents already have SteamCMD.
  3. Build your game with an earlier step, for example Unity or Unreal Engine.
  4. Add Steam upload. It uploads the files and gives later steps the BUILD_ID.
  5. Optionally add Steam: check build and Steam: set branch live after your tests. These two call Steam's Web API and need a Web API key, not SteamCMD.

Two kinds of secret

  • The Steam build account (user name, password and Steam Guard data) is used by the steps that run SteamCMD: Steam upload, DRM wrap and Workshop item.
  • The Steam Web API key is a Secret text credential. Check build and Set branch live use it.

Neither is ever written into a script or shown in the log.

What Buildspawn will not do

  • A build cannot set the default branch live. The names default and public are refused. Set the default branch live on the Builds page in Steamworks.
  • A build cannot create a branch. Make the branch in Steamworks first.
  • If Steam wants the account holder to confirm a change on the Steam Mobile app, the step stops with a message. It never waits for a phone.

Permission to set a branch live

Setting a build live has its own permission, Steam / Set branch live, on the build configuration. The person who starts a build that sets a branch live needs it. Without it the step stops before anything is sent to Steam.

Agents

The SteamCMD steps need steamcmd on the agent. Buildspawn reads it from the agent's tool report and holds the build back from agents that lack it. Steam upload works on Windows, Linux and macOS, and a Windows depot can be uploaded from a Linux agent, because an upload only copies files. The agent needs a connection to Steam.
