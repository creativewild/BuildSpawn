Game builds and stores

Build your game with Unity or Unreal Engine, then send it to Steam or the Epic Games Store, all from one build configuration.

When to use it

Use these steps for a game pipeline: get the code from Perforce or Git, build with the engine, then upload the result to a store and put it on a branch.

How to set it up

  1. Set the version control of the build configuration.
  2. Add a build step for your engine: Unity or Unreal Engine.
  3. Add the store steps you need. Each store has an install step, an upload step and some extra steps. Add the store credential first.
  4. Click Save and Run.

A worked example

Skyforge builds a Unity game from Perforce on a Windows agent, then uploads it to Steam. See Build Unity from Perforce and upload to a Steam branch. For the Epic Games Store, see Publish a build to the Epic Games Store.

What you see when it runs

Each step is a block in the build log. Upload steps print the files sent and the build ID the store gave. Secrets are hidden in the log.
