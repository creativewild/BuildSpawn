Credentials parameter

A pick of one stored credential when a build starts.

When to use it

Use it when people choose which account a build uses, for example a test account. The build gets the ID of the credential, not its secret.

How to set it up

  1. Open the build configuration and go to Settings › Parameters.
  2. Add a credentials parameter (from a Pipeline parameters block or the type's own form).
  3. Choose the Credential type, tick Required if needed, and pick a Default Value.
  4. Click Save. The Parameters tab saves as you work, so there is no other Save button.

A worked example

Parameter STORE_ACCOUNT, type Steam build account, default steam-build. A step that takes a credential ID is set to %STORE_ACCOUNT%. At run time the step finds the credential by its ID.

What you see when it runs

The Run dialog lists credentials of that type that you may use. The value is the credential ID. The secret is never shown.

Problems and fixes
