Choice parameter

A list from which people pick one item.

When to use it

Use it when only a few values make sense: Development, Shipping or Debug; Win64, PS5 or Switch.

How to set it up

  1. Open the build configuration and go to Settings › Parameters.
  2. Click Add parameter.
  3. Choose Value type › Select.
  4. Type the Items, one per line. The first line is the default.
  5. Click Save. The Parameters tab saves as you work, so there is no other Save button.

A worked example

Parameter PLATFORM with items Win64, PS5, Switch. With Allow multiple on, a step receives Win64,PS5 when two are ticked.

What you see when it runs

The Run dialog shows a drop-down list. The Parameters tab says Asked when the build runs with the type choice.
