File parameter

A file that the person starting the build uploads.

When to use it

Use it when a build needs a file you do not keep in version control: a one-off config, a list of test accounts.

How to set it up

  1. Open the build configuration and go to Settings › Parameters.
  2. Add a parameter of the file type. A file parameter is always a Configuration parameter.
  3. Type the File location and, if you like, a Description.
  4. Click Save. The Parameters tab saves as you work, so there is no other Save button.

Every field

FieldWhat it doesDefaultExample
File locationThe path in the workspace where the uploaded file is put. This is also the parameter name.Emptyconfig/overrides.json
DescriptionShown in the Run dialog.EmptySettings for this run

A worked example

A file parameter config/overrides.json. When you run the build, you pick a file in the Run dialog. A step reads config/overrides.json in the workspace.

What you see when it runs

The Parameters tab shows Chosen when the build runs instead of a value. The Run dialog shows a file chooser. The file is copied into the workspace before the steps run.

Problems and fixes

ProblemWhat to do
Environment kind is refusedA file parameter is a configuration parameter only. Choose Configuration.
The file is missing in the workspaceNobody chose a file in the Run dialog. A build started by a trigger gets no file.
