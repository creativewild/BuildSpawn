Boolean parameter

A checkbox that is on or off.

When to use it

Use it for a yes or no choice: clean build, upload to the store, run the slow tests.

How to set it up

  1. Open the build configuration and go to Settings › Parameters.
  2. Click Add parameter.
  3. Choose Value type › Checkbox.
  4. Set Value to the checked or the unchecked value.
  5. Click Save. The Parameters tab saves as you work, so there is no other Save button.

A worked example

Parameter CLEAN, checked value -clean, unchecked value empty. The Unreal Engine step has %CLEAN% in its arguments. A tick adds -clean.

What you see when it runs

The Run dialog shows a checkbox. The step reads the checked or unchecked value as text.
