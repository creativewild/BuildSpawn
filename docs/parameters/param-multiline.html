Multi-line string parameter

Text with line breaks, such as a list of levels or release notes.

When to use it

Use it when one line is not enough: release notes, a list of maps to cook, one file name per line.

How to set it up

  1. Open the build configuration and go to Settings › Parameters.
  2. Add a parameter of the multi-line type (it comes from a Pipeline parameters block or from a configuration that already has one). The table shows it with its value.
  3. Edit the Name, Default Value and Description.
  4. Click Save. The Parameters tab saves as you work, so there is no other Save button.

Every field

FieldWhat it doesDefaultExample
NameThe parameter name.EmptyMAPS
Default ValueMany lines of text.EmptyOne map per line
DescriptionShown under the field in the Run dialog.EmptyMaps to cook, one per line

A worked example

A parameter RELEASE_NOTES holds the notes for the store page. A PowerShell step writes them to a file for the upload step:

Set-Content notes.txt $env:RELEASE_NOTES

What you see when it runs

The Run dialog shows a large text area. Line breaks are kept in the value.

Problems and fixes

ProblemWhat to do
A batch script breaks on the second lineA value with line breaks does not fit on one batch line. Read it as an environment variable in a PowerShell step.
