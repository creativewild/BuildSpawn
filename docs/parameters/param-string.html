String parameter

A single line of text with a default value.

When to use it

Use it for short free text: a branch name, a version, a platform. A Text parameter with Any and no run dialog settings is saved as this type.

How to set it up

  1. Open the build configuration and go to Settings › Parameters.
  2. Click Add parameter.
  3. Choose Value type › Text.
  4. Type the Name and the Value.
  5. Click Save. The Parameters tab saves as you work, so there is no other Save button.

A worked example

A parameter BRANCH with default main. A step uses %BRANCH%. For a release, someone types release/1.4 in the Run dialog.

What you see when it runs

The Run dialog shows a text box with the default. The step receives the value as %BRANCH% and, for an env. parameter, as an environment variable.
