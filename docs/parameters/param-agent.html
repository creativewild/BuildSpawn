Agent parameters

Values that describe the machine a build runs on, such as its name, operating system and free disk space.

When to use them

Use them in two places. In Agent requirements, to pick a machine (for example agent.os.family equals windows). In a step, to read facts about the machine the build runs on, as %agent.name%.

How to use them

  1. Open the build configuration and go to Settings › Agent requirements to add a rule on an agent parameter.
  2. Or type %agent.name% in a step field or a script. The build reads it from the agent that runs the step.
  3. To add your own agent parameters, open the agent in Agents and add a parameter. Names that start with agent. are reserved. A name starts with a letter or digit and holds letters, digits, ., _ and -, up to 100 characters. A value is up to 1000 characters.

An administrator can also show chosen environment variables of the agent as env.NAME. Only the ones listed are read, because environment variables can hold secrets.

A worked example

A Unreal Engine build needs a Windows machine with 50 GB free. Add two rules in Agent requirements: agent.os.family equals windows and agent.work.dir.free.mb is at least 50000. In a step, print where it ran:

echo Built on %agent.name% in pool %agent.pool%

What you see when it runs

The log shows the value in place of the reference, for example Built on win-build-01 in pool Windows. The agent's page lists all its parameters in blocks: agent, system, folders and environment.
