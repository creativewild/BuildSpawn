Asked parameters (prompt)

How a parameter asks for its value when a build starts, or keeps one fixed.

When to use it

Use it to decide what people see in the Run dialog. Some values must be typed every time (the version to release). Others must never change (the SDK path).

How to set it up

  1. Open the build configuration and go to Settings › Parameters.
  2. Click Edit on a parameter, or Add parameter.
  3. Click Customize the run dialog.
  4. Choose Display, and fill in Label and Description. Tick Read-only if nobody may change the value.
  5. Click Save.

Every field

FieldWhat it doesDefaultExample
Display: NormalThe field is in the Run dialog. A plain Run starts the build at once with the defaults.NormalNormal
Display: HiddenThe field is left out of the Run dialog. The configured value is a fixed value the build always uses. Hidden is not protection: anyone who can read the build configuration can see the value.-Hidden
Display: PromptThe Run button opens the Run dialog every time, so people must look at the value.-Prompt
LabelShown in the Run dialog in place of the name.The nameVersion to release
DescriptionShown under the field.EmptyLike 1.4.0
Read-onlyThe configured value is always used. A build request cannot change it.OffOn

A worked example

The release build has RELEASE_VERSION, a Text parameter with a Regex rule \d+\.\d+\.\d+, label Version to release and display Prompt. The nightly schedule starts the same build with a fixed value, so it needs an explicit value too (see Ask for a value when a build starts).

What you see when it runs

The Parameters tab shows Asked when the build runs and the value type for asked parameters, and Fixed value for hidden ones. The Run dialog opens when you click Run and lists the label, description and rules.

Problems and fixes

ProblemWhat to do
A build started by a trigger has no valueA trigger, the API or the command line uses the default. Give the parameter a safe default, or use a Not empty rule so the build is refused.
Someone changed a read-only valueThey cannot. The configured value is used.
