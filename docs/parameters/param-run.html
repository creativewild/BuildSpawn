Run parameter

A pick of one finished build of another build configuration.

When to use it

Use it when a build works on the result of another one: test the build a person picks, or sign a chosen package.

How to set it up

  1. Open the build configuration and go to Settings › Parameters.
  2. Add a run parameter (from a Pipeline parameters block or the type's own form).
  3. Type the Project and choose a Filter.
  4. Click Save. The Parameters tab saves as you work, so there is no other Save button.

Every field

FieldWhat it doesDefaultExample
NameThe parameter name.EmptyPACKAGE_BUILD
ProjectThe build configuration whose builds can be picked.EmptyGame/Windows Build
DescriptionShown in the Run dialog.EmptyThe build to test
FilterWhich builds are offered: All Builds, Completed Builds Only, Successful Builds Only or Stable Builds Only.All BuildsStable Builds Only

A worked example

A run parameter PACKAGE_BUILD for Game/Windows Build, filter Stable Builds Only. A tester picks #212 in the Run dialog. A step reads the build's address from the parameter.

What you see when it runs

The Run dialog shows a drop-down list of builds. The build page shows the chosen build as a link.

Problems and fixes

ProblemWhat to do
The list is emptyThe other build configuration has no build that matches the filter, or you cannot see it.
