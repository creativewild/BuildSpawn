Password parameter

A secret value that Buildspawn stores encrypted and never shows.

When to use it

Use it for a key, token or password that a build needs. See Secrets and Vault for how to use it in scripts.

How to set it up

  1. Open the build configuration and go to Settings › Parameters.
  2. Click Add parameter.
  3. Choose Value type › Password.
  4. Type the Value.
  5. Click Save. The Parameters tab saves as you work, so there is no other Save button.

Every field

FieldWhat it doesDefaultExample
NameThe parameter name. Choose Environment variable as kind so scripts can read it.EmptySTEAM_UPLOAD_KEY
Default ValueThe secret. Stored encrypted, never shown again. Editing shows Stored. Leave empty to keep it.Empty(hidden)
DescriptionShown in the Run dialog.EmptyUpload key

A worked example

Parameter env.STEAM_UPLOAD_KEY, a Password. A PowerShell step runs upload-tool --key $env:STEAM_UPLOAD_KEY.

What you see when it runs

The table shows dots. The Run dialog shows Concealed with a Change Password button. The log shows dots if the value is printed.

Problems and fixes

ProblemWhat to do
The step fails: a secret cannot be written into a scriptRead it from the environment: $env:NAME, $NAME or %NAME% in a batch file.
