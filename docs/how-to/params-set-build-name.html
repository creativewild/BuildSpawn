Set the build name from a script

Name each build after the version and the changelist.

When to use this

Use it so the build page and History show a name that means something, such as 1.4.212-CL48213.

Steps

  1. Open the step that knows the version (Settings › Build steps).
  2. Add a line that prints a buildNumber message (below).
  3. Save and run.

A worked example

Write-Host "##buildspawn[buildNumber '1.4.%build.counter%-CL%build.vcs.number%']"

A name can use %build.counter%, a parameter, %build.vcs.number%, {build.number} for the name so far, and %% for a percent sign. It can be 200 characters at most.

What you see when it runs

The build page and the History tab show 1.4.212-CL48213. The number and address of the build stay the same.

Problems and fixes

ProblemWhat to do
The name did not changeAn unknown parameter or a password in the name is refused. The log says why.
