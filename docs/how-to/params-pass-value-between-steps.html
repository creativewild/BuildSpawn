Pass a value from one step to the next

Work out a value in one step and use it in a later step.

When to use this

Use it when a step discovers something that later steps need: a version, a package name, a folder.

Steps

  1. Open the first step of the build configuration (Settings › Build steps).
  2. In its PowerShell script, read the value and print a setParameter message (below).
  3. In a later step, type %version% where the value belongs.
  4. Save and run.

A worked example

$v = (Get-Content Build\version.txt).Trim()
Write-Host "##buildspawn[setParameter name='version' value='$v']"

A later step: powershell -File Build\ci.ps1 -Stage package -Version %version%.

What you see when it runs

The console shows the message line. The later step shows the value in its command. Use the name env.VERSION instead to get an environment variable.

Problems and fixes

ProblemWhat to do
The value is missing in the same stepIt reaches only the steps after the one that printed it.
The message is refusedOnly a step's own script can send it. The log says why.
