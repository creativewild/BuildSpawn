Use a secret in PowerShell

Read a password parameter in a PowerShell step without printing it.

When to use this

Use it to give a key or token to a tool.

Steps

  1. Open Settings › Parameters and click Add parameter.
  2. Name it STORE_TOKEN, choose Kind › Environment variable (env.) and Value type › Password. Type the token and click Save.
  3. In the PowerShell step write the script below.
  4. Do not write %STORE_TOKEN% in the script: Buildspawn refuses to put a secret into a script.

A worked example

upload-tool --token $env:STORE_TOKEN

For a credential you share between build configurations, use a credential and the Use secret text(s) or file(s) build feature.

What you see when it runs

The console shows dots wherever the value would appear.

Problems and fixes

ProblemWhat to do
The step fails with a secret messageRead the value from the environment variable named in the message.
