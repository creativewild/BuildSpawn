Watch the server from a terminal

Point the buildspawn terminal program at any Buildspawn server to watch its builds, queue and agents live, and stop builds or take agents offline, with no browser.

Before you start

  • You have the terminal program. It comes with every server download: bin\buildspawn.exe on Windows, bin/buildspawn on Linux and macOS. The Windows setup and the Linux packages put it on the PATH. You don't need a server on your own computer to use it.
  • You can reach the server's address from your computer, for example http://buildserver:8080.
  • A terminal at least 80 columns wide. From 110 columns the monitor uses its wide layout. Windows Terminal shows colours and symbols best.
  • To stop builds, cancel queue items or take agents offline, you need an API token. Without one the monitor is read only.

Steps

  1. In the web interface, make an API token: your initial at the top right, Security, Add new token, a name such as terminal on studio-pc, Generate. Copy the token. See API tokens.
  2. Save the token in a text file with one line: your user name, a colon and the token. Keep the file private.

    On Windows, in PowerShell:

    Set-Content -NoNewline -Path "$env:USERPROFILE\.buildspawn-token" -Value "docs:11f3c9a0e5b27d48c6a1f09e3b7d5c2a84"

    On Linux and macOS:

    echo "docs:11f3c9a0e5b27d48c6a1f09e3b7d5c2a84" > ~/.buildspawn-token
chmod 600 ~/.buildspawn-token
  3. Start the monitor with the server's address and the token file: 
    buildspawn --url http://buildserver:8080 --token-file ~/.buildspawn-token

    On Windows, in the program folder, type .\bin\buildspawn.exe instead of buildspawn, and $env:USERPROFILE\.buildspawn-token for the file.

  4. The Overview opens. Press 2 for Builds: every build of the last 24 hours, newest first.
  5. Press f to show only one result, for example only failed builds. Press / and type to filter by job, agent or cause, such as HT3.
  6. Use ↑ and ↓ to select a build. The card below the list shows its agent, cause and last five results. Press Enter to read its log, o to open it in your browser, or x to stop a running build.
  7. Press 3 for Queue to see why each build waits. Press c to cancel the selected item or p to move it to the front.
  8. Press 4 for Agents. Select an agent and press d to take it offline, for example before you restart the machine.
  9. Press q to quit.

Use it in scripts

Every view has a text twin that prints once and exits. Use them in scheduled tasks or chat bots:

buildspawn builds --failed --limit 5 --url http://buildserver:8080 --token-file ~/.buildspawn-token

Command or optionWhat it does
builds --failed, --running, --limit NThe Builds table as text.
queueThe Queue table, with the reason each item waits.
agentsThe Agents table.
--jsonPrints the table as JSON instead, for other programs to read.
--once --view builds --cols 110Draws one frame of the monitor as text and exits, for a log file or a quick look.
--no-colorPlain text without colours.

Set BUILDSPAWN_URL and BUILDSPAWN_TOKEN_FILE once in your shell profile. Then plain buildspawn opens the monitor on that server with your token.

Check it worked

  • The top line says ● Serving and the server's address, with LIVE at the right. The time in the bottom right corner moves every 2 seconds.
  • The bottom line says Signed in and your user name.
  • In the Builds view, the hint at the bottom says x stops the selected build. That means your token is used and actions work.

Troubleshooting

ProblemWhat to do
Typing buildspawn on Windows opens the Buildspawn app instead.In the program folder, Windows finds Buildspawn.exe first. Type .\bin\buildspawn.exe, or open a new terminal anywhere else after the Windows setup.
x, c or d is refused, and the Builds view hint does not say x stops the selected build.The token file is missing, has more than one line, or holds a revoked token. Check the file and the token's Last used time on your Security page.
The monitor can't connect.Open the same address in a browser on the same computer. Include the port and http:// or https://. A firewall or a server that listens on 127.0.0.1 only blocks other computers.
Boxes are drawn with odd characters.The old Windows console can't draw them. Use Windows Terminal, or add --glyphs ascii.
