Build a .sln with MSBuild

Restore the NuGet packages of a Visual Studio solution and build it with MSBuild on a Windows agent.

Before you start

  • A Windows agent with Visual Studio or the Build Tools.
  • An administrator has added an MSBuild installation under Settings › Tools. See Tools.
  • A solution in your workspace, here Tools/BuildTools.sln.

Steps

  1. Open the build configuration and go to Settings › Build Steps.
  2. Add a NuGet Installer step named Restore packages with Solution Tools/BuildTools.sln.
  3. Add an MSBuild step named Build tools.
  4. Pick the installation in MSBuild Version.
  5. Set Project File to Tools/BuildTools.sln and Command Line Arguments to /p:Configuration=Release /m.
  6. Tick Set build to unstable if there are warnings if warnings should be seen.
  7. Click Save and run the build.

Check it worked

The console shows the restored packages, then the MSBuild output. Compiler errors and warnings are marked in the log. The build is successful when MSBuild ends with no errors.

Troubleshooting

  • No installation to pick. Add one under Settings › Tools, with the folder of MSBuild.exe.
  • Missing packages. Make sure the NuGet Installer step is above the MSBuild step.
  • The agent has no Visual Studio. Run the build configuration on a Windows agent that has it.
