Sign in with Entra ID

Let your studio sign in to Buildspawn with Microsoft work accounts, and give the Game Dev group its rights, from the first click to the first sign-in.

Before you start

  • You are a system administrator of Buildspawn, and you can reach the Entra admin centre with a role that may register applications (for example Application Administrator). Someone with the Global Administrator or Privileged Role Administrator role must grant admin consent in step 9.
  • Buildspawn URL on Settings › System is the address people really use, for example https://build.nightlight.example/. See System settings.
  • The group Game Dev exists in Entra ID and holds the developers.
  • Keep a second browser window open and signed in to Buildspawn while you work.

Steps

In the Entra admin centre

  1. Open entra.microsoft.com, go to Identity › Applications › App registrations and click New registration.
  2. Name it Buildspawn. Choose Accounts in this organizational directory only.
  3. Under Redirect URI choose Web and type https://build.nightlight.example/securityRealm/finishLogin. Click Register.
  4. Copy the Application (client) ID and the Directory (tenant) ID from the Overview.
  5. Open Certificates & secrets › New client secret, add it, and copy the secret Value at once.
  6. Open API permissions › Add a permission › Microsoft Graph › Application permissions. Add User.Read.All and Group.Read.All, then click Grant admin consent.

In Buildspawn

  1. Open Settings › Security. Under Security Realm choose Entra ID.
  2. Paste the Client ID, keep Client Secret and paste the Secret, paste the Tenant.
  3. Type your own work account, dana.k@nightlight.example, in Test user principal name or object id, and click Verify configuration. Wait for the green message.
  4. Under Authorization choose Entra ID Matrix-based security.
  5. In Add from Entra ID type your name, pick yourself and click Add. Open the card and tick Administer.
  6. Add the group Game Dev in the same way. Tick Read under Overall, and under Build configuration tick Read, Build, Cancel and Workspace.
  7. On Authenticated Users tick Read under Overall.
  8. Click Save.

Check it worked

  1. Open a private browser window and go to the Buildspawn address. You are sent to the Microsoft page.
  2. Sign in with your work account. You come back to Buildspawn and the top bar shows your name.
  3. Open Settings. You can, because you have Administer.
  4. Ask a developer from Game Dev to sign in. They see the projects and can run builds, but Settings is missing.

Troubleshooting

ProblemWhat to do
Microsoft says the redirect URI does not match.It must be exactly <Buildspawn URL>/securityRealm/finishLogin. Fix it in the app registration under Authentication, or tick Callback URL from request under Advanced.
Verify configuration fails.Check the client ID, tenant and secret. Copy the secret Value, not its ID.
You are locked out after saving.Follow the recovery steps on Security realms.
The picker finds nobody.Admin consent for the Graph permissions is missing.
A developer signs in but sees nothing.Add Read under Overall for the group or for Authenticated Users.
