Always clean up, and collect logs after a failure

Make a clean-up step run even when the build fails, and a log step run only after a failure.

Before you start

  • A build configuration with a step that can fail, for example a test step with the ID tests.

Steps

  1. Open Settings › Build Steps and add a Command Line step named Stop test server.
  2. Under Execution set Execute step to Always, even if build stop command was issued.
  3. Add a Command Line step named Collect crash dumps and set it to Only if build status is failed.
  4. Drag both steps to the end of the list and click Save.
  5. Optional: in a script, check BUILD_STEP_STATUS_TESTS to see how the tests ended.

Check it worked

On a failed build the Build steps card shows the tests as failed, the dump step as succeeded and the clean-up step as succeeded. On a green build the dump step shows as skipped with the build has not failed.

Troubleshooting

  • The clean-up step is skipped. Check that it is below the step that fails, and that its policy is not the default.
