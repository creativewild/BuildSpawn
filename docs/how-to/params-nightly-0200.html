Run nightly at 02:00

Build every night at two o'clock on weekdays.

When to use this

Use it for a nightly build, cook or test run.

Steps

  1. Open the build configuration and go to Settings › Triggers.
  2. Click Add new trigger, then Add next to Schedule Trigger.
  3. Choose Custom.
  4. In Cron line type 0 2 * * 1-5.
  5. Click Save.

A worked example

For every day at 02:00, choose Every day, hour 2, minute 0. To spread several builds, leave the minute empty: it becomes H.

What you see when it runs

The Triggers page shows On a cron schedule or Daily at 02:00, and the summary says Runs every day at 02:00.

Problems and fixes

ProblemWhat to do
It runs at the wrong hourThe time zone of the server is used. Add TZ=Europe/London as the first line of a custom schedule.
