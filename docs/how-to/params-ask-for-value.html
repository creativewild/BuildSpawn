Ask for a value when a build starts

Make the Run button ask for a version before the build begins.

When to use this

Use it when a person must decide something for each build, such as the version to release.

Steps

  1. Open the build configuration and go to Settings › Parameters.
  2. Click Add parameter. Name it RELEASE_VERSION, kind Configuration parameter, value type Text.
  3. Click Show allowed value, choose Regex and type \d+\.\d+\.\d+. Type a message: Use a version like 1.4.0.
  4. Click Customize the run dialog. Set Display to Prompt, Label to Version to release.
  5. Click Save.
  6. Click Run on the build configuration. The Run dialog opens. Type the version and click Run.

A worked example

A step uses it: powershell -File Build\release.ps1 -Version %RELEASE_VERSION%.

What you see when it runs

The Run dialog shows Version to release. A value like abc is refused with your message and the build does not start.

Problems and fixes

ProblemWhat to do
A schedule starts the build with an empty valueGive a default value, or run the build only by hand.
