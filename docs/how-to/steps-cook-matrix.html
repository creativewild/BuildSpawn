Cook several platforms with a Matrix block

Write the cook step once and let Buildspawn run it for every platform and configuration.

Before you start

  • A build configuration with a script that takes a platform and a configuration, here Build\Cook.bat.
  • Agents or a pool for each platform.

Steps

  1. Open Settings › Build Steps and click Add Parallel block. Name it Cook.
  2. Click Change to Matrix.
  3. Add the axis platform with the values Win64, PS5, XboxSeriesX and the axis config with Development, Shipping.
  4. Under Exclude add a row for platform = PS5 and config = Development.
  5. Add a Command Line step in the block: Build\Cook.bat %platform% %config%.
  6. Under Run on send PS5 and XboxSeriesX to pool:Consoles.
  7. Set Max at once to 3 and Files sent back to Saved/StagedBuilds/%platform%/**.
  8. Click Save block and run the build.

Check it worked

The build page shows a grid with one cell per combination. Re-run in a cell runs that combination again. The console has one lane per combination.

Troubleshooting

  • Too many combinations. The limit is 256. Add exclude rows or remove values.
  • A step does not see the value. Use %platform% in the field, or read the environment variable platform.
