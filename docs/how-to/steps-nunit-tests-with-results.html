Run NUnit tests and see the results

Run your NUnit tests on every build and read the passed and failed tests on the build page.

Before you start

  • A Windows agent with the NUnit 3 console runner (nunit3-console) on its PATH.
  • A built test assembly, here Tests/bin/Release/Game.Tests.dll. Build it in an earlier step.

Steps

  1. Open the build configuration and go to Settings › Build Steps.
  2. Add an NUnit step named Unit tests.
  3. Put Tests/bin/Release/Game.Tests.dll in Test assemblies.
  4. Put Slow in Exclude categories to skip slow tests.
  5. Tick Run recently failed tests first, so a test that broke last time is run first.
  6. Optional: set Code coverage to Coverlet or dotCover if the tool is on the agent.
  7. Click Save and run the build.

Check it worked

Open the build. The Build steps card shows the step as succeeded, or unstable when a test failed. Open the Tests tab for each test. With coverage on, the totals show on the build page. See Changes, artifacts and tests.

Troubleshooting

  • nunit3-console not found. Install it, or set Console runner.
  • No tests run. Check the path in Test assemblies.
  • The failed-first pass is skipped. The first build with the option on runs the suite once.
