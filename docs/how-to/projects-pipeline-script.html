Make a Pipeline from a script

Create a Pipeline build configuration, write the script in Buildspawn or keep it in version control, and handle the sandbox.

The studio builds the launcher with a Pipeline. First the script is typed in Buildspawn to try it. Then it moves to a script file in Git.

Before you start

  • The Create permission on the project.
  • For the SCM version: a Git or Perforce repository that holds the file, and a credential that may read it.

Steps

Write the script in Buildspawn

  1. Open the project and click New Item. Type Launcher.
  2. Under Type choose Pipeline. Click Create.
  3. Open the Pipeline tab. Definition is Pipeline script.
  4. Type the script into Script. Leave Use Groovy Sandbox on.
  5. Click Save and Run.
pipeline {
  agent any
  stages {
    stage("Build") { steps { bat "build.bat" } }
    stage("Test")  { steps { bat "test.bat" } }
  }
}

Move the script to version control

  1. Put the same text in a file such as ci/build.pipeline in the repository and commit it.
  2. Open the Pipeline, Settings › Pipeline. Set Definition to Pipeline script from SCM.
  3. Choose the SCM and fill in the repository and credential.
  4. In Script Path replace the name the field starts with by the path of your file, for example ci/build.pipeline. Leave Lightweight checkout on.
  5. Click Save and Run.

Handle the sandbox

  1. If a build fails with Scripts not permitted to use method ..., ask an administrator to open Script approval in the global settings.
  2. The administrator reads the signature and approves it only if it is safe.
  3. Run the build again.

Check it worked

  1. The build page shows the stages Build and Test as a graph with times.
  2. Settings › Build Steps lists the stages read from the script.
  3. Edit the file in Git, commit and run again: the build uses the new file.

Troubleshooting

ProblemWhat to do
Script file not foundThe Script Path or the branch is wrong.
Scripts not permitted to use methodThe sandbox blocked it. Get it approved or change the script.
The script waits for approvalThe sandbox is off and you are not an administrator. Turn it on.
