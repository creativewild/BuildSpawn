Pause a whole project

Stop all automatic builds in a project, for example during a branch freeze, and resume later.

Release 1.4 of Skyforge is frozen for two days. The studio pauses the project Skyforge/Main so no trigger starts a build. Testers can still start one by hand.

Before you start

  • The Configure permission on the project.

Steps

Pause

  1. Open the project Main and click Pause and archive.
  2. In Why it is paused type Release 1.4 freeze until Friday.
  3. Click Pause.

Resume

  1. Open the project again, click Pause and archive.
  2. Click Resume.

Check it worked

  1. The page says Paused by ... on ... with your reason.
  2. A build configuration inside shows Paused from above.
  3. Triggers and polling do not start builds. Click Run on one: it still starts.
  4. Builds that were running finish.

Troubleshooting

ProblemWhat to do
A build configuration inside is still paused after ResumeIt also has its own pause. Open its Pause tab.
I want nothing to run, not even by handArchive the project instead. See Pause and archive.
