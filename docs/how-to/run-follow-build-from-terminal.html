Follow a build from the terminal

Watch a running build's log scroll by in a terminal, find the build that failed last night, and stop a build, without opening a browser.

Before you start

  • You have the terminal program, buildspawn. It comes with every server download. See The terminal program.
  • You can reach the server's address from your computer, for example http://buildserver:8080.
  • To stop a build you need an API token. To only read, you need none. See Watch the server from a terminal for how to make the token file.

Steps

Follow a running build

  1. Start the monitor on your server: 
    buildspawn --url http://buildserver:8080 --token-file ~/.buildspawn-token
    On Windows, from the program folder, type .\bin\buildspawn.exe.
  2. Press 2 for the Builds view. It lists every build of the last 24 hours, newest first. Running builds show a progress bar and a percentage.
  3. Press f and choose the result running, or press / and type part of the build configuration's name, for example Windows.
  4. Select the build with ↑ and ↓. The card below the list shows its agent, its cause and the result of the last five builds.
  5. Press Enter. The Logs view opens with this build's log.
  6. Press f to follow the log. New lines appear as the build writes them. Press PgUp to scroll back, and f again to follow again.
  7. Press l to change the level and / to filter the lines, for example error. Press s to save the log to a file.
  8. Press 2 to go back to the build list, or o to open the build in your browser.

Stop the build

  1. In the Builds view, select the running build.
  2. Press x. The bottom line says x stops the selected build when your token is in use. See Stop a build.

Without the live screen, for scripts

Every view has a text version that prints once and exits:

buildspawn builds --running --url http://buildserver:8080 --token-file ~/.buildspawn-token
buildspawn builds --failed --limit 5 --json

A worked example

You start the nightly Game / Windows Build before you leave, and want to know at home whether the cook has started. On your laptop:

Buildspawn 1.9.3  http://buildserver:8080
 Start  Job                       #   Result            Time   Agent
▸ 23:02  Game/Windows Build        #8  ▶ ██████ 42%   31:10  win-build-01
  22:41  Engine/Unit Tests         #4  ✓ success         5:12   win-build-02

You press Enter on the running build, then f, and watch the Cook content step go by. When it says the cook is done, you press q and go to bed.

What you see when it works

  • The Builds view refreshes by itself, every 2 seconds by default, and says LIVE at the top right.
  • The log view shows the build's lines with times, as the browser console does.
  • After x, the build ends as aborted in the list.

Problems and fixes

ProblemWhat to do
x is refused.The monitor has no valid token. Check the token file: one line, user:token, and a token that was not revoked.
Typing buildspawn on Windows opens the app.Type .\bin\buildspawn.exe in the program folder, or open a new terminal elsewhere after the Windows setup.
The log does not move.The step may not write output. The block in the browser console says Waiting for output then. Press Space to check that the screen is not frozen.
The monitor can't connect.Open the same address in a browser. Include the port and http:// or https://.
