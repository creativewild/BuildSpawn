Run on every Perforce submit

Start a build when a change is submitted to Perforce.

When to use this

Use it to build each submit quickly. You can poll, or let Perforce call Buildspawn.

Steps

  1. Open the build configuration and go to Settings › Triggers.
  2. To poll: add the VCS Trigger, set Poll schedule to H/5 * * * * and a Quiet period of 30.
  3. To start at once: add P4 triggered build. (or Perforce root: build when the Perforce server triggers it on a Perforce root). Copy the line it shows.
  4. On the Perforce server, run p4 triggers and add the line to the list.
  5. Save, then submit a test change.

A worked example

Skyforge uses the second way for the Windows Build. A submit to //depot/game/main starts a build within seconds.

What you see when it runs

The build's change log lists the changelist. %build.vcs.number% is that number.
