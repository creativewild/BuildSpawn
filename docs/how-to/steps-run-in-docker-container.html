Run steps in a Docker container

Run a step inside a container image, so the agent needs Docker but not the tool.

Before you start

  • Docker running on the agent.
  • An image that has the tool, here python:3.12.

Steps

  1. Open the build configuration and go to Settings › Build Steps.
  2. Add a Python step named Check assets. Choose Module and type pytest.
  3. Scroll to Container settings. In Run step within container type python:3.12.
  4. Open Container options if you need an Image platform, a Pull policy or extra docker run arguments.
  5. Click Save and run the build.

Check it worked

The step runs in a new container with the workspace mounted, and the build continues on the agent. Files the step writes in the workspace are there afterwards.

Troubleshooting

  • Docker could not be started on this agent. Install Docker there.
  • The daemon did not answer. Start the Docker service.
  • A Windows image on a Linux agent. Run the step on a Windows agent.
  • A JDK or environment tool is refused. The image brings its own tools. Set the JDK to Inherit and the environment tool to None.
