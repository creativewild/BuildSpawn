Run B when A succeeds

Start the Unit Tests build after the Linux Server Build succeeds.

When to use this

Use it when one build must follow another.

Steps

  1. Open the build configuration Unit Tests (this is B) and go to Settings › Triggers.
  2. Click Add new trigger, then Add next to Finish Build Trigger.
  3. In Build configurations to watch type Game/Linux Server Build (this is A).
  4. Keep Stable so that only a good A starts B.
  5. Click Save. If B must test exactly A's code, also add a snapshot dependency on A (Settings › Dependencies).

A worked example

Each stable Linux Server Build now starts Unit Tests. If B needs A's files, add an artifact dependency.

What you see when it runs

The Triggers page of B says after Game/Linux Server Build finishes. The log of A says it triggered B.

Problems and fixes

ProblemWhat to do
B does not startThe result of A was worse than Stable, or the name is wrong.
