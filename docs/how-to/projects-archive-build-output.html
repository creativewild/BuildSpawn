Archive build output

Keep the files of a build so people can download them later, and reuse them in other builds.

The Windows Build writes the game to Output/Win64. The studio wants the zip files kept with the build and the symbols left out.

Before you start

  • A build step that writes the files into the workspace.
  • The Configure permission.

Steps

Add the post-build action

  1. Open the build configuration, click Settings, then Post-build Actions.
  2. Click Add post-build action and choose Archive the artifacts.
  3. In Files to archive type Output/Win64/**/*.zip.
  4. Open More options. In Excludes type **/*.pdb.
  5. Tick Archive artifacts only if build is successful.
  6. Click Save.

Use the files in another build

  1. Open the other build configuration, Settings › More › Dependencies.
  2. Add an artifact dependency on Windows Build with the rule Output/Win64/*.zip => packages. See Dependencies.

Check it worked

  1. Run the build. The build page has an Artifacts list with the zip files.
  2. The log says Archived N artifacts.
  3. Download one file and open it.

Troubleshooting

ProblemWhat to do
No files found to archiveThe pattern does not match. It is relative to the workspace. Check the step that makes the files.
The disk fills upKeep the artifacts of fewer builds. See Keep the last 30 builds.
