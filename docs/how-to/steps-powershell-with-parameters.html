Run a PowerShell script with parameters

Pass the configuration and output folder from your build parameters to a PowerShell script in your repository.

Before you start

  • A Windows agent with PowerShell. Windows PowerShell 5.1 is enough.
  • A script in your repository, here Build/pack.ps1.
  • Build parameters CONFIG and OUT_DIR on the build configuration. See Parameters.

Steps

  1. Open the build configuration and click Settings › Build Steps, then click Add build step.
  2. Click the PowerShell tile and name the step Pack build.
  3. Set Run to File and Script file to Build/pack.ps1.
  4. In Arguments, type one argument per line:
    -Config
%CONFIG%
-Out
%OUT_DIR%
    Build parameters in %name% form are filled in when the step runs. Each line stays one argument, so a value with spaces is safe.
  5. Leave Add -NoProfile argument on. If the agent's policy blocks scripts, tick Bypass the execution policy.
  6. The script reads its parameters:
    param([string]$Config, [string]$Out)
Write-Host "Packing $Config into $Out"
  7. Click Save and run the build.

Check it worked

Open the build and its console. The step block shows the PowerShell command and Packing Shipping into Builds\Win64. For a secret, do not use an argument: set a password parameter and read $env:NAME in the script.

Troubleshooting

  • The policy blocks the script. Tick Bypass the execution policy.
  • Arguments are empty in the script. Check that Script execution mode is the file mode. In stdin mode arguments are not passed.
  • The script file was not found. The path is relative to the Working directory.
