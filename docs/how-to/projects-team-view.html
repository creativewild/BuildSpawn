Make a tab that shows only your team's build configurations

Add a view to the Projects page so the build team sees its own builds first, without the noise of everything else.

Before you start

  • You need the permission to create views. If you do not see a + at the end of the tab bar, ask an administrator.
  • Name your build configurations with a team prefix, for example Engine-Win64 and Engine-PS5. A pattern is then easy to write. See Views for every field.

Steps

  1. Open the Projects page. Under the page title, click + at the end of the tab bar.
  2. Type the Name Engine team. Under Type choose List View. Click Create.
  3. Type a Description, for example Builds owned by the engine team.
  4. Under Jobs tick Recurse in subfolders, so builds inside projects are found too.
  5. Tick Use a pattern instead. In Pattern type (.*/)?Engine-.*. This matches every build configuration whose name starts with Engine-, at the top or in any project.
  6. Under Filters click Add Build Configuration Filter and choose Status Filter. Pick Enabled build configurations only, so old paused ones stay out.
  7. Under Columns, check the list. Add Last Failure if the team wants to see when a build last broke.
  8. Click Save.

What you see

The new tab Engine team appears next to All. Open it: the table lists only the build configurations that match. The Summary on Edit View says how many items it shows now, for example Shows 6 items.

Make it the first tab people see

An administrator can open Settings › System and choose Default view Engine team. Everyone then lands on that tab. Or keep a private tab in My Views.

Problems and fixes

ProblemWhat to do
The tab is empty.The pattern must match the whole name. Check the prefix and the path, and end the pattern with .*.
A new Engine- build is missing.The pattern finds new builds by name. If you ticked builds by hand instead, tick the new one.
You want to delete the tab.Open it, click ⋯ and choose Delete View. The build configurations stay.
