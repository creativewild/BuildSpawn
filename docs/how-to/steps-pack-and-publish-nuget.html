Pack and publish a NuGet package

Build a package of a shared game library and push it to the studio feed, with the API key kept secret.

Before you start

  • A .nuspec file, here Packaging/Framework.nuspec.
  • A feed address and an API key. Create a Secret text credential that holds the key, here nuget-feed-key. See Secrets.
  • nuget.exe on the agent's PATH.

Steps

  1. Open the build configuration and go to Settings › Build Steps.
  2. Add a NuGet Pack step named Pack framework. Set Specification to Packaging/Framework.nuspec, Output directory to out and Version to 1.4.%build.number%.
  3. Tick Keep the packages as build artifacts and Clean output directory.
  4. Add a NuGet Publish step named Publish framework. Set Packages to out/*.nupkg.
  5. Set Package source to your feed URL and pick the credential in API key.
  6. Put -SkipDuplicate in Arguments.
  7. Click Save and run the build.

Check it worked

The console shows the package created and then the push, with the key shown as ********. The .nupkg file is under Artifacts.

Troubleshooting

  • The credential is not found. It must be Secret text and this project must be allowed to use it.
  • The feed says the version exists. Raise the version or keep -SkipDuplicate.
  • No package to push. Check that the pack step wrote to out.
