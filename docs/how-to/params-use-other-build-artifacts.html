Use another build's artifacts

Copy the files of a cook build into your installer build.

When to use this

Use it when a build needs files that another build made.

Steps

  1. Open the Game/Installer build configuration and go to Settings › Dependencies.
  2. Add a snapshot dependency on Game/Cook Content, so both build the same revision.
  3. Click Add artifact dependency, choose Game/Cook Content and Get artifacts from › Build from the same chain.
  4. In Artifact rules type Cooked/**/* => Content. Tick Clean destination paths before downloading artifacts.
  5. Click Save. Make sure the cook build keeps Cooked/** as artifacts.

A worked example

A step in the installer reads Content\... in its workspace.

What you see when it runs

The installer's console lists the files copied before the steps begin.

Problems and fixes

ProblemWhat to do
Same chain is refusedAdd the snapshot dependency first.
No artifacts foundThe cook build did not keep them. Check its artifact settings.
