Retry a flaky step

Run a step again when it fails for a reason that comes and goes, such as a dropped network share.

Before you start

  • A step that sometimes fails on a crash or a timeout, and the exit code it ends with.

Steps

  1. Open Settings › Build Steps and click Edit on the step.
  2. Scroll to Execution.
  3. Set Retry on failure to 2 and Wait between attempts to 30 seconds.
  4. In Only for exit codes type -1, 3221225477 so only a crash is retried.
  5. Click Save.

Check it worked

When the step fails with a listed code, the console says Attempt 1 failed with exit code -1, which is in the retry list. Waiting 30 s, then attempt 2 of 3. A step that finally passes says Step passed on attempt 2 of 3.

Troubleshooting

  • A real error is retried. List the crash codes so a normal failure (exit code 1) fails at once.
  • The step is not retried. The exit code is not in the list: Attempt 1 failed with exit code 1, which is not in the retry list.
