Run Python tests and see the results

Run pytest with a Python step and show the results on the build.

Before you start

  • Python 3 on the agent, with pytest installed.
  • Tests in tools/tests.

Steps

  1. Open the build configuration and go to Settings › Build Steps.
  2. Add a Python step named Check assets. Choose Module, type pytest.
  3. In Arguments put tools/tests and, on the next line, --junitxml=reports/assets.xml.
  4. In Test reports put reports/assets.xml.
  5. Click Save and run the build.

Check it worked

The build gets a Tests tab. A failed test makes the step unstable and the results are still recorded.

Troubleshooting

  • No results. Check the path in Test reports against the --junitxml path.
  • pytest not found. Use Environment tool › venv and install packages in an earlier step.
