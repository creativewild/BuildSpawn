System settings

The System page holds the server-wide settings: the server address, how builds are queued, limits and defaults, and the settings of the bundled plugins.

When to use it: when you set up a new server, when builds queue too fast or too slowly, when the server sits behind a proxy, or when you want a default (such as a build timeout or a build discarder) to apply to every build configuration.

How to open it

  1. Click Manage in the left rail, then System. The address is /configure. You need the Manage permission to change the settings. People with the System read permission see the page read-only.
  2. Use the On this page index on the left to jump to a section.
  3. Change what you need. The Save and Apply buttons stay at the bottom of the window. Apply saves and stays on the page. Save saves and leaves it.

Each field has a small ? button. Click it to read the help for that field. Some sections only appear when they have something to set. For example, the Fingerprint storage list only shows when more than one storage type is installed.

Global Build Discarders

A build discarder deletes old builds. A build configuration's own discarder runs only after a build finishes. A global discarder also runs on a timer, so changes to the rules apply even when no new builds run. Click Add to add one.

DiscarderWhat it does
Build Configuration Build DiscarderRuns every build configuration's own discarder on a timer. It does nothing for a build configuration that has no discarder. Only one of these can be added.
Specific Build DiscarderPick a discarder type (such as Discard old builds with days and number to keep). It runs after every build and on a timer, for every build configuration.

A game studio that keeps large builds can add a specific discarder that keeps the last 20 builds everywhere, so disk space stays under control.

What you see when it works

  • After Save you return to the Manage page. After Apply a short Saved message shows and you stay on the page.
  • A build in its quiet period waits in the queue and starts when the time is over.
  • A name that breaks the naming rule shows your Description as the error when you create the build configuration.

Problems and fixes

ProblemWhat to do
A message says the reverse proxy set up is broken.Set Buildspawn URL to the address people really use, including any path.
Fields cannot be edited.You only have the System read permission. Ask for the Manage permission.
Save refuses a value.The field shows a red message. Typical causes: the retention interval is outside 1 to 60, the name pattern is not a valid regular expression, or the proxy port is above 65535.
A warning keeps coming back after you hide it.Hide it with its tick box under Administrative monitors, then Save.
The global time-out does not stop one build configuration.That build configuration has its own time-out and Are individual jobs allowed to overwrite this global timeout? is on.
