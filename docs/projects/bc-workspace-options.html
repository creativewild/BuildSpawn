Workspace options

What happens around getting the sources onto the agent: retries, a custom workspace folder, and how a Pipeline run is saved and resumed.

When to use it

Use them when a checkout is unreliable, when you want the sources in a fixed folder, or when a Pipeline must not resume after a restart. They are cards on General, with the Dependency options on the Dependencies tab.

How to set it up

  1. Open the build configuration and click Settings. Then click General.
  2. Open Checkout options. Set Retry count, or turn on Use a custom workspace and type the Directory.
  3. For a Pipeline, open Run behaviour and choose the options below.
  4. Click Save.

To remove a workspace before a build, use the build feature Delete the workspace before the build.

A worked example

The Unity project Unity Windows Build keeps its sources in E:\ws\skyforge-unity so the Unity Library folder survives. Retry count is 2 because the Perforce server sometimes drops the first connection.

What you see when it runs

The log shows each retry of the checkout. With a custom workspace the log shows that folder as the workspace.

Problems and fixes

ProblemWhat to do
Two builds break each otherThey share the custom folder. Use Run one build at a time in Build options.
The folder is refusedEnter the directory, or turn the option off.
The retry count is refusedIt must be 0 or a whole number above it.
