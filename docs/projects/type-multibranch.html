Multibranch Pipeline

A Multibranch Pipeline makes one Pipeline build configuration for each branch of a repository that has a pipeline script file.

When to use it

Use it when every branch must be built by the same script, for example each feature branch of the launcher. New branches are found by a scan, and removed branches are cleaned up. It is under More types on the New Item page.

How to set it up

  1. Open the project and click New Item. Type a name.
  2. Under More types choose Multibranch Pipeline. Click Create.
  3. Under Branch Sources click Add source and fill in the repository.
  4. Under Build Configuration, Mode is the choice that reads the pipeline script file. Set the Script Path: replace the name the field starts with by the path of your file.
  5. Set the scan trigger and the orphaned item strategy. Click Save. The first scan starts.

A worked example

The launcher repository has branches main, release/1.4 and feature/login. The Multibranch Pipeline Launcher shows three Pipelines, one per branch.

What you see when it runs

The page shows the branch projects with their results. The Scan log says which branches were found. Orphaned branches are removed by the strategy.

Problems and fixes

ProblemWhat to do
No branches are foundThe scan found no script file at the Script Path, or the credential cannot read the repository. Open the scan log.
Too many builds start on a scanSet Build strategies or the branch name rule for automatic triggers.
