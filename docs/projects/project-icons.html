Project icons

Show the platform of a project or build configuration with an icon in the tree, in tables and in the Run dialog.

Why use them

A tree with PS5 Build, Xbox Series Build and Windows Build is easier to scan when each has its platform icon. The icon shows in the project tree, in tables, in the page header and in the Run dialog. The build result is shown separately, as a dot.

Set an icon

  1. Open the project or build configuration and click Settings. For a build configuration open General.
  2. Under Icon click the platform. The Sidebar preview shows how it looks.
  3. Choose an Icon colour if you like (see below).
  4. Click Save.

Icon colour

ChoiceWhat it does
DefaultThe theme's normal icon colour.
FavouritesColours your team keeps for reuse. Manage edits the list. They are shared with everyone.
ColoursA set chosen to read on both the light and the dark theme.
CustomA colour as RRGGBB, one for the light theme and one for the dark theme. Clear removes it.

What is inherited

A project without a choice keeps the project icon. A build configuration without a choice shows the generic icon. The icon is saved with the item and kept when you rename, move or copy it.

A worked example

In Game, PS5 Build gets PlayStation, Xbox Series Build gets Xbox and Windows Build gets Windows. The project Tools gets the Tools icon.

Problems and fixes

ProblemWhat to do
The icon does not showSave the page. The tree updates on the next page load.
The icon is hard to read in the dark themePick a colour from Colours, which reads on both themes, or set a separate dark colour.
