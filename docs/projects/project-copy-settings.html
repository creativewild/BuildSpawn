Copying settings

Make a new build configuration from an existing one, from a template, or copy settings from a project, and choose what happens to the settings it inherits.

Copy an existing item

  1. Open the project where the copy should go and click New Item.
  2. Type the new name. Check the ID.
  3. Under Start from choose Copy of an existing item. In Copy from type part of a name and pick the item. Every item you can read is listed.
  4. Under Settings of the copy choose one of the two cards (below).
  5. Click Create.
ChoiceWhat it does
Keep inheritingThe copy uses the settings of the project it is created in. Pick this when the copy should follow its new project.
Make inherited settings its ownThe copy keeps running the same steps and parameters, whatever the project holds. Pick this when you copy into another project and want the build to stay the same.

Overrides are kept either way. The copy gets a new ID and starts with no build history.

Start from a template

  1. Under Start from choose Template. The list shows the templates you can use in this project, with how many steps and parameters each has.
  2. Pick one. Leave Keep linked to the template on if the new item should follow later changes to the template. Clear it to copy the steps once.
  3. Choose the type and click Create.

Share settings with a project

To give many build configurations the same steps or parameters, put them on the project instead of copying. See Share settings with a whole project.

A worked example

The studio copies Windows Build into Game as Switch Build with Keep inheriting. The copy picks up the steps of the project Game. A copy of Windows Build into the project Tools with Make inherited settings its own keeps the Game steps as its own.

Problems and fixes

ProblemWhat to do
Copy of an existing item is missingThe server has no items that you can read.
Template is missingNo template is within reach of this project. Templates of a project can be used in it and in the projects below.
The copy builds differentlyYou chose Keep inheriting and the new project passes other steps. Choose Make inherited settings its own.
