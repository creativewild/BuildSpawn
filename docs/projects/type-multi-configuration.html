Multi-configuration project

One project that runs the same steps for every combination of values, such as each platform and each build type. It is no longer offered for new items.

When to use it

New work should use the Matrix mode of Parallel blocks instead. You write the steps once, give the values, and every combination runs as its own side. A Multi-configuration project that already exists keeps working: you can open, build, configure and copy it.

How to set it up

  1. Open the existing Multi-configuration project and click Settings.
  2. Under Configuration Matrix add or change the axes.
  3. Set the Combination Filter and the Execution Strategy if needed. Click Save.

A worked example

An old Tools/Asset Pipeline is a Multi-configuration project with the axes PLATFORM and CONFIG. The studio leaves it as it is and builds new tools with a Matrix block.

What you see when it runs

The project page shows a grid of the configurations with their latest result. Each cell links to its build.
