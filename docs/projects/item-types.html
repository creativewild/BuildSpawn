Item types

An item is anything in the project tree: a project, a build configuration, a Pipeline or a template. You pick the type when you create it on the New Item page.

Create an item

  1. Open the project the new item goes in. Click New Item in the page header, or + above the project tree.
  2. Type the Item name. The page checks it as you type. These characters are not allowed: ? * / \ % ! @ # $ ^ & | < > [ ] : ;. The name must be unique in the project.
  3. Check the ID. It is made from the ID of the project and the name, and you may edit it. See IDs.
  4. Check Created in. Click Change to pick another project.
  5. Choose Start from: Empty, Copy of an existing item or Template.
  6. Under Type click a card.
  7. Click Create. The button stays off until everything is valid and says why. The summary card on the right says what will be created.

The types

TypeWhat it isPage
Build configurationSteps run one after another, with the step editor, templates and Perforce roots. Use it for most builds.Build configuration
PipelineA script file that defines stages, parallel work and approvals.Pipeline
Build configuration templateSteps and parameters that several build configurations share.Build configuration template
ProjectGroups projects. Holds shared settings, credentials, Perforce roots and permissions.Project
Multibranch PipelineCreates a set of Pipeline build configurations, one per branch of a repository. Under More types.Multibranch Pipeline

The cards are grouped as Builds (Build configuration, Pipeline, Template), Organise (Project) and More types.

Types that are hidden

Two types are not offered on the New Item page. Items of these types that already exist keep working. You can open, build, configure and copy them. Only the choice of the type for a new item is gone.

TypeWhy it is hiddenPage
Multi-configuration projectThe Matrix mode of Parallel blocks does the same job inside a normal build configuration.Multi-configuration project
Organization FolderIt is not created by hand on this page. It scans an account of a code host and makes a Multibranch Pipeline for each repository it finds.Organization Folder

A Start from choice of Copy of an existing item shows only when the server has items. Template shows only when a template is within reach of the project.
