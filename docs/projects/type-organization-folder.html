Organization Folder

An Organization Folder scans an account or organization of a code host and makes a Multibranch Pipeline for each repository it finds. It is no longer offered for new items.

When to use it

It can no longer be created by hand on the New Item page. One that already exists keeps working. Make a Multibranch Pipeline for each repository instead.

How to set it up

  1. Open the existing Organization Folder and click Settings.
  2. Under Projects change the Repository Sources and the Project Recognizers.
  3. Set the Property strategy and the Build strategies. Click Save.

A worked example

An old Platform project scans one account and has a Multibranch Pipeline for each repository. The studio keeps it and makes new ones by hand.

What you see when it runs

The folder lists the repositories it found. A scan log shows what changed.
