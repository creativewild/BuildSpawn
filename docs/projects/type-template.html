Build configuration template

A template holds steps, parameters, post-build actions and roots that several build configurations share. It never runs by itself.

When to use it

Use it when Windows Build, PS5 Build and Xbox Series Build do almost the same. Change the template once and every build configuration that uses it follows. The page Templates explains how to create, attach and detach.

How to set it up

  1. Open the project that should own the template and click New Item.
  2. Type a name, for example Platform build.
  3. Under Type choose Build configuration template. Click Create.
  4. Add the steps, parameters and roots to share. Click Save.

A worked example

The project Game has the template Platform build with Sync, Cook and Package steps and the parameter PLATFORM. Each platform configuration attaches it and sets its own value.

What you see when it runs

A template has no Run button. Build configurations that use it show its steps with a chip carrying the template name.

Problems and fixes

ProblemWhat to do
