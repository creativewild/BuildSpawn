Agent Requirements

Which agents may run this build configuration, as rules on agent parameters.

When to use it

Use it when only some machines can build: an agent with Windows and Visual Studio, or a PS5 devkit agent. Builds wait for an agent that meets every rule. The page also lists the compatible agents. It is under More on the Settings tabs.

How to set it up

  1. Open the build configuration and click Settings. Then click More › Agent Requirements.
  2. Click Add requirement.
  3. Choose the Parameter (for example agent.os.name), the Condition and the Value.
  4. Check the list of Compatible agents on the right. Click Save requirement.

A worked example

Windows Build needs agent.os.family equals Windows and agent.pool equals Unreal. The page shows 3 of 8 agents are compatible.

What you see when it runs

A queued build that no agent can run says why on the Queue page. The Compatible agents list shows each agent as compatible or incompatible with the reason.

Problems and fixes

ProblemWhat to do
The build waits foreverNo agent meets all rules. Open this tab and look at Incompatible and Why.
A tool requirement from a step blocks buildsThe agent cannot see the tool. Fix the agent, or Ignore the requirement.
A name is refusedA parameter name has letters, digits, dots, dashes and underscores. A condition other than exists needs a value.
