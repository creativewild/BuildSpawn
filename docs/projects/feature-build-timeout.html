Terminate a build if it is stuck

Stops a build that runs too long or goes quiet. In Buildspawn this lives under Failure conditions.

In the list of build features this is called Terminate a build if it's stuck.

When to use it

Use it for builds that can hang, such as a cook that waits for a window to close. You do not add it as a build feature. The time limits are in Failure conditions under Build time.

How to set it up

  1. Open the build configuration, click Settings, then Failure Conditions.
  2. Under Build time choose how the limit is set: Fixed limit, Compared with earlier builds or No new log output.
  3. Set the minutes, and choose the Result (Failed or Unstable). Click Save.

Every field

FieldWhat it doesDefaultExample
Fixed limitFail if the build runs longer than the number of minutes you give.Off90
Compared with earlier buildsLimit = the average of recent successful builds plus a margin in percent.OffMargin 150%
No new log outputFail when the log stays silent for the number of minutes you give.Off20
ResultWhat the build becomes when the limit is reached.FailedFailed

A worked example

The PS5 Build normally takes 40 minutes. The studio picks Compared with earlier builds with a margin of 150%. A build that runs longer than about an hour is stopped and marked failed.

What you see when it runs

The build is stopped. A line in the log says which limit was hit. Time in the queue is not counted. The limit is checked every 10 seconds, so a build can stop up to 10 seconds late.
