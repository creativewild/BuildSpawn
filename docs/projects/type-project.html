Project

A project is a folder. It groups build configurations and other projects, and passes settings down to everything inside.

When to use it

Make one project per game or tool: Game, Engine, Tools. Inside you can make a project per kind of build, such as Main, Drops and Release. A project holds shared steps, parameters, credentials, Perforce roots, templates, documentation links and permissions. The page Projects has the full description.

How to set it up

  1. Open the project the new one sits in, or the Projects page for a top-level project. Click New Item.
  2. Type the name, for example Engine.
  3. Under Type choose Project. Click Create.
  4. On its Settings, add a description, an icon and a colour. Click Save.
