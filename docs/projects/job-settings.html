Job settings

Every setting that is stored with a build configuration, what it holds and where to find it.

What a job setting is

A job setting is a property stored with one build configuration. Most have a place on the tabs of the build configuration. This page lists every one, what it holds and where to find it. The server calls them job properties; in the user interface a job is a build configuration.

FieldWhat it doesDefaultExample

IntervalSeconds. How often the lists (submitted changes, shelves, pending changes, labels, branch streams) are read in the background while someone has viewed the build configuration in the last 30 minutes, or while it has a polling, commit or shelve trigger. The interval is shorter for ten minutes after a change and grows while nothing changes, up to 15 minutes.120300

Settings you do not edit

SettingWhat it is
Based on branchSet by a Multibranch Pipeline on each branch project. You do not edit it.
Generated build configurationMarks a build configuration that a plugin made for one run of another one, as part of a composite build. It is hidden from lists, the tree, search and the dashboard, keeps the access rules of its owner, and is deleted with it or after a retention time.
BuildGraph agent groupMarks a build configuration that a distributed BuildGraph build made for one agent group: which build it belongs to and which agent types may run it. Never made from a form.
