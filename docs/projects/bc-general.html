General

The name, ID, icon, build number and artifact rules of a build configuration, plus how builds are queued, limited, cleaned up and checked out.

When to use it

Open General first when you make a build configuration. It says what the build is called, which icon shows in the tree, how builds are numbered, and how many builds may run at once. Everything else on this page is optional.

How to set it up

  1. Open the build configuration and click Settings. Then click General.
  2. Check the Name and the Build configuration ID. Choose an Icon for the platform.
  3. Set the Build number format if you want names such as 1.4.2.
  4. Open the other cards (Artifacts, Build options, Clean-up rules, Checkout options) if you need them.
  5. Click Save, or Apply to save and stay on the page.

A worked example

The Skyforge Windows Build uses the ID Game_WindowsBuild and the Windows icon. The Build number format is 1.4.%build.counter%, so the first build of the day shows as 1.4.142. Build priority is 10 so it goes before the nightly Linux builds when agents are scarce.

What you see when it runs

The build page and the History list show the display name and the build number format. The project tree shows the icon. The summary card on the right of General shows the next build number and the artifact rules.
