# Buildspawn 1.5 (build 2.589-buildspawn.14)

Buildspawn by [Luis Gomes](https://github.com/creativewild). Installing it over 1.4 keeps your settings and data.
Everything in the 1.4 notes (`..\1.4\NOTES-2.589-buildspawn.13.md`) is included.

How to start it on each system: `START-buildspawn-1.5.html` in this folder.

## Fixed since 1.4

### Builds and steps
- **Parallel blocks:** each side shows **Add step** and **Remove side** again, without hovering, so you can put
  steps into an empty side.
- **Steps with failed tests** show **Unstable** (yellow) in Build steps, the summary and the console, instead of
  Success.
- **Resume** keeps the earlier steps' test results and keeps the build Unstable when a reused step was; tests are
  never counted twice.
- **The "Resumed from" card** is readable: the workspace path wraps only between folders.
- **Build logs:** the batch step's temporary script is named `buildspawn….bat` (and shell steps likewise), and Git
  builds no longer print an old internal warning.

### Parameters and settings
- **Add parameter:** **Type** is next to Name from the start (Text, Choice, Yes or no, Password, File); Remote
  opens the full form with its source and query.
- **Template parameters you override** show "overridden here" with **Reset**.
- **Parameters page:** says the true thing everywhere — a configuration parameter is read as `%NAME%` and is also
  in every step's environment.
- **Section pages** name themselves after their tab in the breadcrumb ("Version Control", "Triggers"…).

### Dialogs and pages
- **Dialogs no longer close when you click outside them.** Use Close, Cancel or Esc.
- **Job Overview:** the Health report and Permalinks cards are gone; the build history uses the full width.
- **History list:** the Duration no longer sits under the Visual button.
- **Add build step / Add build feature:** plain descriptions of what each runner and feature does; no internal
  notes, tags or "not available" lists.
- **Appearance (dark theme):** you can see which theme is chosen.
- **Security page:** the API token list is full width and its buttons are not cut off.
- **Groups:** no empty table flash while the page loads.
- **Test results:** "Tests (1 failure)" without a stray space.
- **Delete View:** the confirmation was titled "todo"; it is "Delete View".

### Agents and pools
- **Moving an agent by hand** ("Move to pool…", the pool page, Create pool) and its Undo now appear in the
  Pool Scheduler's Recent moves and "Moves today".
- **Scheduled moves** show their days in week order, as "Mon–Fri", "Every day" or "Sat, Sun".
- **The built-in agent** has the same name everywhere (scheduler board, moves, borrows, activity).
- **"Next scheduled move"** and long pool names are no longer cut off.
- **GPU names** no longer repeat the vendor ("NVIDIA NVIDIA …").
- **Telemetry:** an agent that disconnects while it is being sampled no longer writes a stack trace to the log.

### Perforce, Unity and Unreal
- **Perforce workspace names** with `${NODE_NAME}` and other variables show a note ("filled in for each agent when
  the build runs") instead of "Unknown Client".
- **No more false "Not currently connected"** (and red dot on the Version Control tab): the name check uses the
  form's own credential.
- **New Perforce roots** name their workspaces `buildspawn-…`; existing jobs keep their old workspace names, so
  nothing re-syncs.
- **Unity step help** shows Windows paths correctly.
- **Unreal step:** "Test metadata server" sits under the fields it checks and shows only when they are used.

### Users and names
- **User names may contain dots** (for example `sam.lee`).
- **Product names:** the old product name is gone from what you see in core and the bundled plugins: plugin
  names and descriptions, credentials ("Global (Buildspawn, nodes…)"), email subjects ("Buildspawn build is
  unstable"), Vault, roles, telemetry, Unity, Unreal and Perforce texts.

## Good to know
- Java 21.0.13.1 (Temurin) is bundled with every server package and agent download, as in 1.4.
- Saved settings, IDs and mail headers are unchanged, so existing jobs, credentials and mail filters keep working.
