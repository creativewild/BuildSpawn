# Buildspawn 1.9.3 (build 2.589-buildspawn.21)

Installing over 1.9.2, 1.9.1, 1.9 or 1.8 keeps your settings and data. Everything in the 1.9.2 notes (`..\1.9.2\NOTES-2.589-buildspawn.20.md`) is also in this release.

How to start it on each system: see `START-buildspawn-1.9.3.html` in this folder.

## Fixes
- **Resume from a step works with Perforce:** a resumed build of a build configuration with a Perforce root failed at its first step with `NullPointerException` in `CredentialsProvider.findCredentialById`. The source records taken over from the failed build (changelist, credential, P4 ticket) now belong to the resumed build. Git roots that tag builds are fixed the same way.
